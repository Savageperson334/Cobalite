# Hardware milestone H0 — identify and inventory, not flash

## Evidence and limits
Public reverse-engineering notes: https://github.com/victorvillena/all8/blob/main/notes/platform.md ; https://github.com/victorvillena/all8/blob/main/notes/multi.md ; https://github.com/victorvillena/all8/blob/main/notes/mod-destinations.md ; https://github.com/victorvillena/all8/blob/main/notes/open-questions.md . Crossflash tooling and its recovery discussion: https://github.com/cliffordmanasseh/crossflash-8 and docs/USING.md. These projects are references, not copied firmware or proof of compatibility with an individual Cobalt8M. Some detailed addresses in all8 are Carbon 1.1 or Argon 3.2, not Cobalt 2.1. Never transplant them without confirming the exact image.

The public notes infer a SAM4 Cortex-M4 panel and SAM E70/S70 Cortex-M7 master and two slave processors. Master handles coordination, note allocation, sequence and FX; each slave renders four voices. Firmware images use a common application base 0x410000 in the studied versions. Model signature and link IDs must stay consistent; preserve bootloader and factory signature. The master has external SDRAM but its usage remains incompletely mapped. Free flash/RAM estimates for other models are not our budget. There are existing mod destination tables on all three roles; expanding these can collide with unrelated objects. Do not equate JS patch IDs with hardware parameter IDs.

## Read-only utility
`node tools/firmware-audit.cjs <panel.syx> <master.syx> <slave.syx>`
The tool accepts three local stock Cobalt update files, rejects malformed frames, wrong device/model ID, mixed roles, incorrect packet index/count, nonzero padding and incorrect per-packet 16-bit checksums. Reports SHA-256 of container and decoded image, image lengths, initial stack/reset vector and plausibility flags. No MIDI, no flash commands, no binary outputs. Based on published frame format, not verified with the user's stock files. A matching checksum does not establish authenticity, firmware version, compatibility or recovery. No proprietary binaries should be committed. Keep backup copies offline and record original updater version, source and acquisition date. Do not submit actual firmware files to the repository.

## Work package order and exit gates
1. Obtain user-owned official firmware files and record model, firmware version, hardware revision if available, updater version, stock preset backup and recovery procedure. Inventory each role and pin exact SHA-256. Do not flash until stock recovery is independently understood.
2. Offline disassembly and mapping, using known Cobalt vectors as landmarks rather than Carbon addresses. Confirm memory ranges, timer and link dispatch, encoder relative deltas and presses, display writes, master parameter and patch dispatch, audio block size and slave oscillator hooks. Map actual switch IDs via read-only observation and compare against virtual panel. No guesses written into patch manifests.
3. Build version-pinned manifest of verified hooks and reserved ranges with expected original bytes, bounds and fail-closed mismatch checks; optional offline emulation where supported. Require original-image re-encoding round trip, disassembly and independent review before any patch output. No bootloader/signature writes.
4. First experimental firmware candidate: minimal one-parameter UI change or one oscillator implementation with stock synthesis and FX intact; test in emulator before hardware. Do not combine panel, DSP and storage rewrites in the first device trial. Preserve known-good stock update set and preset backups. No hardware trial has happened.
5. Budget Cobalite: control-rate routing and motion on master or appropriate shared scheduler, per-voice modulation on slaves, panel local gesture state. Decide whether existing links can carry new control signals with acceptable latency; measure block deadline headroom on each processor. Afterimage's three 2.1-second stereo float32 buffers consume about 2.42 MB at 48 kHz, before other state. Use shared fixed-size pools and effect-specific buffers, measure actual availability. No 64-route browser architecture assumed to fit existing slot tables. Avoid per-sample allocation and repeated transcendentals; use tables and bounded fixed arrays only after measuring quality.

## Current blocker
No official stock file set or physical device is accessible in this environment. This is preparation for actual reverse engineering, not a completed encoder map or safe flash build. No changes made to firmware or device.
